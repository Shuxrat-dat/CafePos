# Центральный Telegram-бот CafePOS

Один бот на все заведения. Владелец подключается нажатием на ссылку, без токенов и номеров чатов.
Бот присылает уведомления и отвечает на команды на узбекском (русский включается командой `/til`).

## Как это устроено

```
 касса заведения A ─┐                       ┌─> владелец A (Telegram)
 касса заведения B ─┼─ HTTPS ─> hub (VPS) ──┼─> владелец B, управляющий B
 касса заведения C ─┘   события и сводки    └─> ...
```

- Токен бота хранится только на сервере с хабом. Кассам он не нужен.
- Касса при подключении получает от хаба свой ключ и одноразовую ссылку `t.me/Бот?start=КОД`.
  Владелец открывает ссылку, нажимает «Start», и чат запоминается.
- Касса присылает события (смена, отмены, скидки, склад, отзывы, ошибки) и сводку цифр. Сводка обновляется
  после оплат и смен, не чаще раза в минуту. Команды бота отвечают по последней сводке.
- В 09:00 по местному времени заведения бот сам присылает итог вчерашнего дня и список закупки.

## Команды бота

| Команда | Что делает |
|---|---|
| `/bugun` | выручка, чеки, средний чек, прибыль за сегодня |
| `/kecha` | то же за вчера, со сравнением с прошлой неделей |
| `/hafta` | последние 7 дней |
| `/ombor` | что нужно купить и на сколько дней хватает остатка |
| `/smena` | текущая смена |
| `/top` | самые продаваемые блюда |
| `/tarmoq` | итог по всем заведениям чата: выручка, доли точек, лучшая; `/tarmoq kecha` и `/tarmoq hafta` — за вчера и за неделю |
| `/sozlamalar` | какие уведомления получать (кнопками) |
| `/til` | язык UZ/RU |
| `/yordam` | список команд |

**Сеть заведений.** Владелец с несколькими точками открывает ссылку подключения каждой кассы с одного и того же чата.
Бот присылает отчёты по каждой точке, а `/tarmoq` (или кнопка «Сеть») собирает общий итог. Каждая точка остаётся
отдельной установкой со своей базой: сеть складывается из их сводок.

Второму и следующему получателю заведения копия базы и ошибки сервера по умолчанию выключены.

## Установка на VPS

1. Создайте бота у @BotFather (`/newbot`) и скопируйте токен.
2. Придумайте общий секрет касс (длинная случайная строка), например `python -c "import secrets;print(secrets.token_urlsafe(32))"`.
3. Создайте файл `hub/.env` (в git он не попадает):

```
HUB_BOT_TOKEN=123456:ABC...
HUB_REGISTRATION_TOKEN=длинный-случайный-секрет
# необязательно:
# HUB_HOST=127.0.0.1
# HUB_PORT=8099
# HUB_DB=/opt/cafepos/hub.sqlite3
```

4. Запуск: `python -m hub`. Для автозапуска используйте `deploy/linux/cafepos-hub.service`.
5. Выставьте хаб наружу по HTTPS через Caddy или nginx (проксируйте на `127.0.0.1:8099`), например:

```
hub.example.uz {
    reverse_proxy 127.0.0.1:8099
}
```

6. В `.env` каждой кассы добавьте:

```
HUB_URL=https://hub.example.uz
HUB_REGISTRATION_TOKEN=тот-же-секрет
```

После перезапуска кассы на странице «Настройки → Telegram» появится кнопка «Подключить Telegram».

Только стандартная библиотека Python (плюс `python-dotenv`, если он установлен). Базу `hub.sqlite3`
включите в резервное копирование: в ней список получателей.

## Безопасность

- Ключ заведения хранится в хабе только в виде хеша. Утечка базы хаба не раскрывает ключи.
- Ссылка подключения одноразовая и действует 48 часов. Тот, кто откроет её первым, станет получателем.
- Команды отвечают только подключённым чатам. Чужим чатам бот цифры не показывает.
- Не открывайте порт хаба наружу без HTTPS: ключи касс ходят в заголовке запроса.
- Если секрет касс утёк, замените `HUB_REGISTRATION_TOKEN` на хабе и во всех кассах. Уже подключённые кассы
  продолжат работать, новые без секрета подключиться не смогут.
