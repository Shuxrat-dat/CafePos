# Демо-сценарий CafePOS (10–15 минут)

Демо работает на отдельной базе `demo.sqlite3`. Данные учебные и одинаковые после каждого сброса;
время заказов отсчитывается от момента заполнения, поэтому **сбросьте демо перед показом**
(Настройки → Восстановить демо-данные), чтобы таймеры на кухне и в зале были «живыми».

## Сценарий показа

1. **Вход и роли.** Страница входа → «Кассир». Переключатель UZ / RU слева внизу.
2. **Зал.** Статусы столов: свободен, занят, ожидает оплаты, бронь; сумма и время обслуживания;
   заявка гостя на столе 7. Фильтр по залам.
3. **Заказ навынос за минимум действий.** «Навынос» → нажать «Самса» два раза, «Капучино»
   (выбор размера и сиропа) → «Оплатить» → «Наличные», быстрая сумма 100 000 → сдача считается сама →
   «Принять оплату» → чек с реквизитами заведения и сдачей → «Печать чека».
4. **Скидка и смешанная оплата.** Стол 1 → «добавить» скидку 10% → «Оплатить» → «Смешанная»:
   карта 60 000, остальное наличными.
5. **Кухня.** Войти как «Повар» (или открыть «Кухня» у владельца): колонки «Новые / Готовятся / Готово»,
   таймеры, подсветка долгих заказов, крупные кнопки. Перевести оплаченный заказ из п.3 по этапам.
6. **Официант.** Войти как «Официант»: видит только свои столы, чужие закрыты замком,
   нет оплаты, склада и отчётов (сервер возвращает «Нет доступа»). Пречек для стола.
7. **Заказы.** Активные / завершённые / отменённые, поиск по номеру, телефону, клиенту; карточка заказа
   со всеми этапами и сменой статуса.
8. **Меню.** Стоп-лист одним переключателем, скрытие с кассы, редактирование блюда с фото,
   модификаторами и техкартой.
9. **Склад.** Остатки, предупреждение «заканчивается», приход, списание с причиной, движение
   (продажи списываются автоматически при оплате).
10. **Отчёты.** Выручка, заказы, средний чек и сравнение с прошлым периодом, динамика по дням или часам,
    способы оплаты, категории, топ блюд, сотрудники, последние оплаты.
11. **Настройки.** Название, логотип, адрес, обслуживание, НДС, текст чека, способы оплаты, язык,
    залы и столы, QR-коды для столов.
12. После показа — «Восстановить демо-данные».

## Ограничения демо

- Фото блюд не загружены: показываются единые иллюстрации категорий. Реальные фото загружаются в карточке блюда.
- Фискальный чек (ОФД / онлайн-касса) не подключён: чек печатается браузером на ленту 80 мм.
- Оплата картой фиксируется кассиром после терминала, интеграции с банковским терминалом нет.
- QR-меню с телефона открывается только по IP-адресу компьютера в локальной сети, не через localhost.
